How it works
3분이면 완료

복잡한 세팅 없이. 내일 오전 10시부터 알림톡이 도착합니다.

01
소셜 간편 가입
구글·네이버·카카오 계정으로 1분 내 계정 생성.
02
네이버 API 연동
어드민 [도구 > API 사용 관리]에서 Customer ID · 액세스 라이선스 · 비밀키 복사 후 입력.
03
통합 광고 대시보드 생성
연동된 데이터로 보고서를 선택해 대시보드 바로 생성. 네이버·구글·메타·카카오 성과를 한 화면에서 확인.
04
광고성과 알림톡 설정 별도 신청
담당자에게 "알림톡 신청" 회신 → 계정 활성화 → 시스템 내 본인인증 1회 완료.
05
매일 오전 10시, 알림톡 + 대시보드 🎉
매일 오전 10시 알림톡으로 전일 성과 자동 수신. 대시보드에서 광고 성과·예산 소진·매체별 현황을 언제든 확인!
